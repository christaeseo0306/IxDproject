# Virtual FaceTime

Figma Slides에서 링크를 타고 들어오면 **가상 인물과의 영상통화**가 시작되는 웹 프로토타입입니다.
내 맥북 카메라가 실제로 켜지고, 준비한 영상이 macOS FaceTime UI 안에서 순서대로 재생됩니다.
후반부에는 CCTV/REC 화면으로 전환되어 그 인물의 삶을 엿보는 연출로 넘어갑니다.

빌드 과정이 없는 정적 HTML/CSS/JS 입니다. 외부 라이브러리도, 인터넷 연결도 필요 없습니다.

---

## 1. 빠른 시작

```bash
# 1) 영상을 videos/ 에 넣습니다 (파일명 규칙은 3번 참고)
# 2) 재생 목록 생성
node tools/build-manifest.mjs

# 3) 로컬 서버 실행 — http://localhost 은 보안 컨텍스트라 카메라가 동작합니다
./serve.sh            # → http://localhost:8000
```

> 영상이 아직 없어도 괜찮습니다. 그대로 열면 **리허설 모드**로 동작해서
> 화면 전환·조작·UI를 미리 연습할 수 있습니다.

## 2. Figma Slides에 연결하기

### 발표 당일 권장 — 로컬 서버 (가장 안전)

Figma Slide의 도형/텍스트에 하이퍼링크로 `http://localhost:8000` 을 넣습니다.

- 발표장 와이파이와 무관하게 동작합니다.
- 영상 용량 제한이 없습니다.
- `http://localhost` 는 브라우저가 보안 컨텍스트로 취급하므로 **카메라 권한이 정상 동작**합니다.
  (`file://` 로 직접 열면 카메라가 차단되니 반드시 서버로 여세요.)

발표 전 체크: 노트북에서 `./serve.sh` 를 띄워두고 → 슬라이드쇼 실행 → 링크 클릭 → 새 탭에서 열림.

### 대안 — GitHub Pages

Settings → Pages → Branch: `claude/dazzling-albattani-vi1z0v` / `/ (root)` 로 배포하면
`https://<계정>.github.io/IxDproject/` 로 접속됩니다. HTTPS라 카메라도 동작합니다.
다만 깃허브는 **파일당 100MB** 제한이 있으니 영상을 미리 압축해야 하고,
발표장 네트워크에 의존하게 됩니다. 백업 경로로만 쓰는 것을 권합니다.

## 3. 영상 준비 — Google Drive 넘버링, 괜찮습니다 (단, 재생 소스로는 쓰지 마세요)

**질문하신 `01`, `02` … 제목 넘버링은 좋은 방식입니다.** 두 가지만 지켜주세요.

1. **자리수를 맞춰 0을 채울 것** — `1, 2, … 10` 이 아니라 `01, 02, … 10`.
   그래야 10번이 2번 뒤로 밀리지 않고 정렬됩니다.
2. **파트를 파일명에 표시할 것** — `call`(영상통화) / `cctv`(엿보기).
   이 토큰 하나로 스크립트가 UI 전환 지점을 자동으로 잡습니다.

```
01_call_첫인사.mp4
02_call_자기소개.mp4
03_call_하루이야기.mp4
04_call_질문.mp4
05_cctv_거실@CAM03.mp4
06_cctv_작업실@CAM05.mp4
07_cctv_현관@CAM01.mp4
```

`@CAM03` 은 CCTV 화면에 표시될 카메라 번호입니다(생략 가능).
파트 토큰 없이 가고 싶다면 `node tools/build-manifest.mjs --cctv-from=5` 처럼
몇 번부터 2파트인지만 알려주면 됩니다.

### ⚠️ 구글 드라이브를 "재생 소스"로 직접 연결하지 마세요

드라이브 공유 링크를 `<video src>` 에 그대로 넣는 건 실패합니다.

- 공유 URL은 영상 파일이 아니라 뷰어 페이지로 리디렉트됩니다.
- CORS가 막혀 있고, 구간 요청(Range)을 제대로 지원하지 않아 탐색이 깨집니다.
- 용량이 크면 "바이러스 검사를 할 수 없습니다" 경고 페이지가 먼저 뜹니다.
- 트래픽 쿼터에 걸리면 발표 도중 갑자기 재생이 멈출 수 있습니다.

**드라이브는 팀 협업·보관용으로 쓰고, 발표 전에 `videos/` 폴더로 내려받아 로컬에서 재생하세요.**
넘버링해둔 파일명이 그대로 재생 순서가 되므로, 받아서 폴더에 넣고 스크립트 한 번 돌리면 끝입니다.

### 인코딩

`.mp4` (H.264 + AAC) 를 권장합니다. 아이폰으로 찍은 `.mov`(HEVC)는 브라우저에서 재생이 안 될 수 있습니다.

```bash
ffmpeg -i 원본.mov -c:v libx264 -crf 20 -preset slow -pix_fmt yuv420p \
       -c:a aac -b:a 192k -movflags +faststart 01_call_첫인사.mp4
```

`-movflags +faststart` 는 꼭 넣으세요. 영상이 즉시 시작됩니다.

## 4. 조작

영상에는 재생/정지 버튼이 없습니다. **전부 키보드로 넘깁니다.**

| 키 | 동작 |
|---|---|
| `→` `Space` `Enter` `↓` | 다음 클립 (발신 화면에선 통화 연결) |
| `←` `↑` `PageUp` | 이전 클립 |
| `1`–`9` / `Home` / `End` | 해당 번호 / 처음 / 마지막으로 |
| `R` | 현재 클립 처음부터 다시 |
| `F` | 전체화면 |
| `M` | 영상 음소거 |
| `C` | 내 카메라 켜기/끄기 |
| `H` | 발표자 패널 (클립 목록, 클릭으로 점프) |
| `Esc` | 통화 종료 화면 |

클릭으로도 다음으로 넘어갑니다. 리모컨(프레젠터)의 다음/이전 버튼은 보통
`PageDown`/`PageUp` 을 보내므로 그대로 쓸 수 있습니다.

### 연출 흐름

```
GATE          클릭 한 번 (카메라 권한 + 오디오 잠금 해제)
  ↓
CALLING       내 카메라가 창 전체를 채우고 발신음이 울립니다
  ↓  →
LIVE  (파트1) 준비한 영상이 상대방 자리에 재생, 내 얼굴은 우상단 PiP
  ↓  →        (파트2 첫 클립에서 신호 획득 글리치)
CCTV  (파트2) REC·타임스탬프·스캔라인이 올라간 감시 카메라 화면
  ↓  Esc
ENDED         통화 시간과 함께 종료
```

클립이 끝나면 **마지막 프레임에서 멈춘 채 대기**합니다. 방향키를 누를 때만 넘어갑니다.
다음 클립은 미리 받아두기 때문에 전환이 끊기지 않습니다.

## 5. 설정 (`videos.json`)

```jsonc
{
  "caller": {
    "name": "서지민",          // 창 좌상단 이름
    "initials": "지민",        // 아바타 글자
    "avatar": "assets/face.jpg" // 프로필 사진 (선택)
  },
  "options": {
    "fit": "cover",            // cover(꽉 채움) | contain(레터박스)
    "glitchMs": 700,           // CCTV 진입 글리치 길이
    "showSelfInCctv": true,    // CCTV 화면에 내 카메라 썸네일
    "cctvClock": "2026-10-08T21:14:03",  // CCTV 타임스탬프 시작 시각
    "ringtone": true,          // 발신음
    "backdrop": "",            // 창 뒤 바탕화면 이미지 (예: assets/desktop.jpg)
    "startFullscreen": false
  },
  "clips": [
    { "src": "videos/01_call_첫인사.mp4", "part": "call", "label": "첫 인사" },
    { "src": "videos/05_cctv_거실.mp4",  "part": "cctv", "label": "아침",
      "cam": "CAM 03", "location": "LIVING ROOM",
      "date": "2026-10-08T07:12:40",   // 이 클립만 다른 시각 표시
      "loop": true }                    // 반복 재생
  ]
}
```

`tools/build-manifest.mjs` 를 다시 돌려도 `caller` / `options` 값은 보존됩니다.

## 6. 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 카메라가 안 켜짐 | `file://` 로 열었을 때 발생합니다. `./serve.sh` 로 localhost에서 여세요. |
| 영상 대신 번호 플레이스홀더 | 파일 경로가 틀렸거나 브라우저가 못 읽는 코덱입니다. H.264 mp4로 변환하세요. |
| 소리가 안 남 | 첫 화면을 **클릭**해야 브라우저 오디오 잠금이 풀립니다. `M` 으로 음소거 확인. |
| 노란 경고 배너 | 매니페스트가 없거나 보안 컨텍스트가 아닙니다. 배너 문구대로 조치하세요. |
| 발표 중 커서가 거슬림 | 2.6초 멈추면 자동으로 사라집니다. `F` 로 전체화면 권장. |

발표 직전 리허설: `H` 를 눌러 발표자 패널에서 클립 목록이 의도한 순서·파트와 맞는지 확인하세요.
빨간 글씨로 표시된 항목은 파일을 못 찾은 클립입니다.
