# Virtual FaceTime

Figma Slides에서 링크를 타고 들어오면 **가상 인물과의 영상통화**가 시작되는 웹 프로토타입입니다.
내 맥북 카메라가 실제로 켜지고, 준비한 영상이 macOS FaceTime UI 안에서 순서대로 재생됩니다.
후반부에는 CCTV/REC 화면으로 전환되어 그 인물의 삶을 엿보는 연출로 넘어갑니다.

빌드 과정이 없는 정적 HTML/CSS/JS 입니다. 외부 라이브러리도, 인터넷 연결도 필요 없습니다.

---

## 0. 가장 쉬운 방법 — 첫 화면에서 영상 고르기

앱을 열고 첫 화면의 **Choose videos…** 버튼을 눌러 영상을 선택하면 끝입니다.
파일을 어디로 옮길 필요도, 폴더를 찾을 필요도 없습니다.
화면 아무 데나 **드래그해서 놓아도** 똑같이 동작합니다.
파일명 앞 숫자 순서대로 재생 목록이 만들어지고, `videos.json` 의 `cctvFrom` 기준으로
파트가 자동으로 나뉩니다. 파일을 복사하거나 이름을 바꿀 필요가 없습니다.

**한 번 넣으면 브라우저에 저장되어 계속 유지됩니다.** 새로고침하거나 브라우저를
껐다 켜도 같은 순서로 그대로 재생됩니다. 되돌리려면 발표자 패널(`H`)의
**Clear saved videos** 를 누르면 `videos/` 폴더 기준으로 돌아갑니다.

### 순서와 파트를 직접 고치기

발표자 패널(`H`)에서 각 줄의 `↑` `↓` 로 순서를 바꾸고, `CALL` / `CCTV` 배지를
눌러 파트를 전환할 수 있습니다. 바꾼 내용도 함께 저장됩니다.
목록 번호는 파일명과 똑같이 **00 부터** 매겨지고, 숫자 키 `0`–`9` 가 그 번호와 1:1로 맞습니다.

## 1. 빠른 시작

```bash
# 1) 영상을 videos/ 에 넣습니다 (00.mp4, 01.mp4 … 숫자만으로 충분합니다)
# 2) 실행 — 재생 목록은 자동으로 맞춰집니다
./serve.sh            # → http://localhost:8000
```

**영상을 추가하거나 파일명을 바꿔도 다시 실행하기만 하면 됩니다.**
`serve.sh` 가 `videos/` 구성이 바뀐 걸 감지해 재생 목록을 자동으로 갱신합니다.
직접 돌리려면 `node tools/build-manifest.mjs` 입니다.

터미널이 번거로우면 폴더 안의 **`start.command` 를 더블클릭**하세요.
터미널이 자동으로 열리면서 서버가 뜹니다.

### ⚠️ "Apple could not verify…" 경고가 뜨면

인터넷에서 받은 실행 파일이라 macOS 가 기본으로 막는 것입니다. 파일 문제가 아닙니다.
**`Move to Trash` 가 아니라 `Done` 을 누르세요.** 그다음 둘 중 하나로 풀면 됩니다.

**방법 1 — 폴더 잠금을 한 번에 풀기 (권장, 이후로는 더블클릭이 바로 됩니다)**

터미널을 열고(`⌘ Space` → `터미널`) 아래를 치고 한 칸 띄운 뒤,
**Finder 에서 이 폴더를 터미널 창으로 끌어다 놓고** Enter:

```bash
xattr -dr com.apple.quarantine 
```

**방법 2 — 터미널에서 바로 실행 (보안 경고 자체가 안 뜹니다)**

```bash
cd            # 한 칸 띄우고 폴더를 터미널로 드래그 → Enter
bash tools/publish.sh      # 올리기
bash serve.sh              # 실행
```

> 영상이 아직 없어도 괜찮습니다. 그대로 열면 **리허설 모드**로 동작해서
> 화면 전환·조작·UI를 미리 연습할 수 있습니다.

## 2. Figma Slides에 연결하기

### 발표 당일 권장 — 로컬 서버 (가장 안전)

영상을 **원본 그대로** 씁니다. 재인코딩도 용량 제한도 없습니다.
`tools/serve.py` 가 구간 요청(Range)을 지원해서, 수백 MB 짜리 영상도
전체를 받기 전에 바로 재생되고 되감기·탐색이 즉시 됩니다.

Figma Slide의 도형/텍스트에 하이퍼링크로 `http://localhost:8000` 을 넣습니다.

- 발표장 와이파이와 무관하게 동작합니다.
- 영상 용량 제한이 없습니다.
- `http://localhost` 는 브라우저가 보안 컨텍스트로 취급하므로 **카메라 권한이 정상 동작**합니다.
  (`file://` 로 직접 열면 카메라가 차단되니 반드시 서버로 여세요.)

발표 전 체크: 노트북에서 `./serve.sh` 를 띄워두고 → 슬라이드쇼 실행 → 링크 클릭 → 새 탭에서 열림.

### 웹사이트로 만들기 — 영상까지 올려서 한 번에

주소만 열면 바로 재생되는 웹사이트로 만들려면, 영상도 저장소에 함께 올려야 합니다.
명령 하나면 됩니다.

폴더 안의 **`publish.command` 를 더블클릭**하면 됩니다. (터미널이면 `./tools/publish.sh`)

압축 → 재생 목록 갱신 → 용량 점검 → 커밋 → 푸시까지 한 번에 합니다.
압축만 풀어 쓰는 폴더라면 저장소 연결도 알아서 합니다 — 처음 한 번 저장소 주소만 물어봅니다.
끝나면 Pages 켜는 주소와 접속 주소를 알려줍니다. 처음 한 번만 Pages 를 켜주세요.

```
Settings → Pages → Source: Deploy from a branch
                 → Branch: (현재 브랜치) / (root) → Save
```

1~2분 뒤 `https://<계정>.github.io/IxDproject/` 로 들어가면 **영상이 바로 재생됩니다.**
이 주소를 Figma Slide 링크에 넣으면, 그 뒤로는 영상을 다시 넣을 일이 없습니다.
팀원들도 주소만 열면 됩니다.

영상을 바꾸거나 추가한 뒤에는 `./tools/publish.sh` 를 다시 돌리면 됩니다.

> GitHub 은 파일당 100MB 제한이 있어 스크립트가 미리 점검합니다. 걸리면
> `./tools/compress.sh 720` 으로 더 줄이면 됩니다.
> 발표장 네트워크가 불안하면 로컬(`start.command`)을 백업으로 함께 준비하세요.

## 3. 영상 준비 — Google Drive 넘버링, 괜찮습니다 (단, 재생 소스로는 쓰지 마세요)

### 가장 간단한 방법 — 숫자만

```
00.mp4
01.mp4
02.mp4
03.mp4
04.mp4
05.mp4
```

이것만으로 충분합니다. **`00` 이 항상 첫 영상**이고, 화면의 번호도 파일명 그대로 표시됩니다.
번호가 `00, 01, 02, 05, 06` 처럼 띄엄띄엄이어도 파일명의 숫자를 그대로 보여주며,
숫자 키 `0`–`9` 가 그 번호와 1:1 로 맞습니다.

**자리수를 맞춰 0을 채워주세요** — `1, 2, … 10` 이 아니라 `01, 02, … 10`.
그래야 10번이 2번 뒤로 밀리지 않습니다.

파트는 `node tools/build-manifest.mjs --cctv-from=5` 로 한 번만 알려주면
`videos.json` 에 기억됩니다.

### 제목을 같이 넣고 싶다면

```
00 - listening to c&c.mp4
01 - Ray introducing.mp4
05_cctv_거실@CAM03.mp4
```

앞 숫자가 재생 순서, 그 뒤가 제목입니다. `call` / `cctv` 토큰을 넣으면
`--cctv-from` 없이도 파트가 자동으로 나뉘고, `@CAM03` 은 CCTV 화면의 카메라 번호가 됩니다.
제목을 넣으면 CCTV 화면 좌하단에 장소명으로 표시되고, 숫자만 쓰면 카메라 이름이 대신 나옵니다.

### 드라이브에서 받아오기

폴더를 통째로 내려받아 `videos/` 에 풀고, 파트 경계를 한 번만 알려주면 됩니다.

```bash
# 드라이브 폴더 → 우클릭 → 다운로드 (zip) → 압축 해제 후 videos/ 로 이동
node tools/build-manifest.mjs --cctv-from=5    # 5번부터 CCTV 파트
```

`--cctv-from` 값은 `videos.json` 에 기억되므로, 영상을 추가한 뒤에는
`node tools/build-manifest.mjs` 만 다시 돌리면 새 클립이 알아서 올바른 파트로 들어갑니다.

### ⚠️ 구글 드라이브를 "재생 소스"로 직접 연결하지 마세요

드라이브 공유 링크를 `<video src>` 에 그대로 넣는 건 실패합니다.

- 공유 URL은 영상 파일이 아니라 뷰어 페이지로 리디렉트됩니다.
- CORS가 막혀 있고, 구간 요청(Range)을 제대로 지원하지 않아 탐색이 깨집니다.
- 용량이 크면 "바이러스 검사를 할 수 없습니다" 경고 페이지가 먼저 뜹니다.
- 트래픽 쿼터에 걸리면 발표 도중 갑자기 재생이 멈출 수 있습니다.

**드라이브는 팀 협업·보관용으로 쓰고, 발표 전에 `videos/` 폴더로 내려받아 로컬에서 재생하세요.**
넘버링해둔 파일명이 그대로 재생 순서가 되므로, 받아서 폴더에 넣고 스크립트 한 번 돌리면 끝입니다.

### 용량이 크면 — 압축 스크립트

4K나 고비트레이트 원본은 노트북에서 버벅이거나 공유가 번거롭습니다.
한 번에 발표용으로 줄일 수 있습니다.

```bash
./tools/compress.sh          # 최대 1080p, 화질 우선 (권장)
./tools/compress.sh 720      # 더 작게
./tools/compress.sh 1080 20  # 높이 1080, CRF 20 (숫자가 낮을수록 고화질)
```

- 세로 영상도 비율을 유지한 채 높이 기준으로만 줄입니다. 기준보다 작은 영상은 건드리지 않습니다.
- **오디오를 검사해서, 원본에 있던 소리가 사라지면 그 파일은 압축하지 않고 원본을 남깁니다.**
- 원본은 지우지 않고 `videos/original/` 로 옮겨 보관하므로 언제든 되돌릴 수 있습니다.
- 압축본이 원본 파일명을 그대로 가져가므로 `videos.json` 은 손댈 필요가 없습니다.

### 인코딩

`.mp4` (H.264 + AAC) 를 권장합니다. 아이폰으로 찍은 `.mov`(HEVC)는 브라우저에서 재생이 안 될 수 있습니다.

```bash
ffmpeg -i 원본.mov -c:v libx264 -crf 20 -preset slow -pix_fmt yuv420p \
       -c:a aac -b:a 192k -movflags +faststart 01_call_첫인사.mp4
```

`-movflags +faststart` 는 꼭 넣으세요. 영상이 즉시 시작됩니다.

## 4. 조작

영상에는 재생/정지 버튼이 없습니다. **전부 키보드로 넘깁니다.**

| 키 | 동작 |
|---|---|
| `→` `Space` `Enter` `↓` | 다음 클립 (발신 화면에선 통화 연결) |
| `←` `↑` `PageUp` | 이전 클립 |
| `0`–`9` / `Home` / `End` | 해당 번호 / 첫 클립 / 마지막 클립으로 |
| `R` | **처음부터 다시 시작** (발신 화면으로 되돌림) |
| `.` | 현재 클립만 되감기 |
| `F` | 전체화면 |
| `M` | 영상 음소거 |
| `C` | 내 카메라 켜기/끄기 |
| `H` | 발표자 패널 (클립 목록, 클릭으로 점프, 재시작 버튼) |
| `Esc` | 통화 종료 화면 |

클릭으로도 다음으로 넘어갑니다. 리모컨(프레젠터)의 다음/이전 버튼은 보통
`PageDown`/`PageUp` 을 보내므로 그대로 쓸 수 있습니다.

### 소리

영상은 음소거 없이 재생됩니다. 브라우저는 사용자 조작 없이 소리 있는 재생을 막기 때문에,
첫 화면의 **통화 걸기** 클릭 시점에 영상 엘리먼트의 오디오 잠금을 미리 풀어둡니다.
그래서 이후 방향키로 넘겨도 소리가 끊기지 않습니다.

재생 직후 소리가 나지 않으면 이유를 화면에 알려줍니다 — 자동재생이 막혔으면
"화면을 클릭하면 소리와 함께 재생됩니다", 영상 자체에 오디오 트랙이 없으면
해당 클립 이름과 함께 알림이 뜨고 발표자 패널에 `무음` 배지가 붙습니다.

`R` 은 **어느 상태에서 눌러도** 통화 시간·클립 위치·CCTV 스킨·발표자 패널을 모두 초기화하고
맨 처음 발신 화면으로 돌아갑니다. 리허설을 반복하거나 발표 중 흐름이 꼬였을 때 쓰세요.
발표자 패널(`H`)의 **처음부터 다시 시작** 버튼도 같은 동작입니다.

### 연출 흐름

```
GATE          클릭 한 번 (카메라 권한 + 오디오 잠금 해제)
  ↓
CALLING       내 카메라가 창 전체를 채우고 발신음이 울립니다
  ↓  →
LIVE  (파트1) 준비한 영상이 상대방 자리에 재생, 내 얼굴은 우상단 PiP
  ↓  →        (파트2 첫 클립에서 신호 획득 글리치)
CCTV  (파트2) REC·타임스탬프·스캔라인이 올라간 감시 카메라 화면
  ↓  Esc
ENDED         통화 시간과 함께 종료
```

클립이 끝나면 **마지막 프레임에서 멈춘 채 대기**합니다. 방향키를 누를 때만 넘어갑니다.
다음 클립은 미리 받아두기 때문에 전환이 끊기지 않습니다.

## 5. 설정 (`videos.json`)

화면에 나오는 모든 문구는 영어입니다. 아래 `caller.name` 등도 영어로 넣으세요.

```jsonc
{
  "caller": {
    "name": "Raymond Kim",     // 창 좌상단 이름
    "initials": "RK",          // 아바타 글자 (2글자 권장)
    "avatar": "assets/face.jpg" // 프로필 사진 (선택)
  },
  "options": {
    "fit": "cover",            // cover(꽉 채움) | contain(레터박스)
    "glitchMs": 700,           // CCTV 진입 글리치 길이
    "showSelfInCctv": true,    // CCTV 화면에 내 카메라 썸네일
    "cameraOffInCctv": true,   // CCTV 파트에서 내 카메라를 끈다
    "cctvClock": "2026-10-08T21:14:03",  // CCTV 타임스탬프 시작 시각
    "cctvFrom": 5,             // 몇 번 영상부터 CCTV 파트인지 (빌더가 기억)
    "ringtone": true,          // 발신음
    "backdrop": "",            // 창 뒤 바탕화면 이미지 (예: assets/desktop.jpg)
    "startFullscreen": false
  },
  "clips": [
    { "src": "videos/00 - listening to c&c.mp4", "part": "call", "label": "listening to c&c" },
    { "src": "videos/05 - FitnessRoom.mp4", "part": "cctv", "label": "FitnessRoom",
      "cam": "CAM 01", "location": "FITNESS ROOM",
      "date": "2026-10-08T07:12:40",   // 이 클립만 다른 시각 표시
      "loop": true }                    // 반복 재생
  ]
}
```

`tools/build-manifest.mjs` 를 다시 돌려도 `caller` / `options` 값은 보존됩니다.

## 6. 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 카메라가 안 켜짐 | `file://` 로 열었을 때 발생합니다. `./serve.sh` 로 localhost에서 여세요. |
| 영상 대신 번호 플레이스홀더 | 파일 경로가 틀렸거나 브라우저가 못 읽는 코덱입니다. H.264 mp4로 변환하세요. |
| 소리가 안 남 | 첫 화면 **통화 걸기** 버튼을 클릭해야 오디오 잠금이 풀립니다. `M` 으로 음소거 상태 확인. |
| 특정 클립만 무음 | 발표자 패널(`H`)에 `무음` 배지가 붙습니다. 그 영상에 오디오 트랙이 없는 것이니 다시 내보내세요. |
| 노란 경고 배너 | 매니페스트가 없거나 보안 컨텍스트가 아닙니다. 배너 문구대로 조치하세요. |
| 발표 중 커서가 거슬림 | 2.6초 멈추면 자동으로 사라집니다. `F` 로 전체화면 권장. |
| 폴더에 넣기가 번거로움 | 첫 화면에 영상을 드래그해서 놓으면 바로 불러옵니다(0번 참고). |

발표 직전 리허설: `H` 를 눌러 발표자 패널에서 클립 목록이 의도한 순서·파트와 맞는지 확인하세요.
빨간 글씨로 표시된 항목은 파일을 못 찾은 클립입니다.
